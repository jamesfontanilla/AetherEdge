# AetherEdge Starter Templates

This directory houses ready-to-deploy starter templates for vibe coders and AI agents:

1. **`starter-nextjs`**: Next.js App Router with `@aether/edge` pre-configured (D1 + Postveil Passkeys).
2. **`starter-vite-react`**: Ultra-fast single page application with client-side edge routing and zero-egress asset caching.
3. **`starter-ai-rag`**: Minimalist AI RAG app with Cloudflare AI Gateway proxy and semantic caching.
4. **`starter-astro`**: Content and documentation site with static/SSR hybrid deployment.
