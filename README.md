# AetherEdge (`Aether.run`)

> **The Sovereign All-in-One PaaS — 1-Click Zero-Egress Deployments with Zero PaaS Tax.**

AetherEdge is a unified, edge-native developer platform engineered to liberate developers and vibe-coders from the fragmented, high-cost PaaS subscription tax.

---

## ⚡ The 8 Primitives in One Dashboard

1. **Edge Hosting & SSR (`aether.deploy`):** Replaces Vercel & Render. Sub-35ms global V8 cold starts.
2. **Relational SQL Database (`@aether/db`):** Replaces Supabase. 500MB free storage, zero-pause edge SQLite.
3. **Zero-Egress Object Storage (`@aether/storage`):** Replaces AWS S3. Backblaze B2 via Cloudflare Bandwidth Alliance ($0/GB egress).
4. **Sovereign Auth & Identity (`@aether/auth`):** Replaces Clerk. Native Sign in with Postveil (`*.postveil.me`) + Google/GitHub secrets.
5. **Transactional Outbound Mail (`@aether/mail`):** Replaces Resend & Brevo. High-deliverability AWS SES in 3 lines of code.
6. **In-Memory KV Cache (`@aether/kv`):** Replaces Upstash Redis. Microsecond session and rate-limit storage.
7. **Edge Crons & Background Tasks (`@aether/cron`):** Replaces Trigger.dev. Scheduled midnight jobs directly on the edge.
8. **AI Gateway & Proxy Cache (`@aether/ai`):** Replaces OpenRouter. Automatic prompt caching to eliminate duplicate LLM costs.

## 🚀 Instant Deployment

Deploy any project from your terminal in one command:

```bash
npx aether deploy
```

Or connect your GitHub repository for automatic preview and production deployments to:
`https://[project].[yourname].aether.run`
